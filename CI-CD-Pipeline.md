# CI/CD Pipeline Concepts

## Continuous Integration (CI)
Automatically collects code from repositories, builds it, and runs tests on every commit.

Example: Every time code is pushed to GitHub, Jenkins builds and tests the project automatically.

## Continuous Delivery (CD)
Transfers built applications to testing or staging servers, awaiting manual approval before production.

## Continuous Deployment
Automatically deploys code to production after passing tests without human intervention.

Difference:
- Delivery: Staging/testing before production with manual approval.
- Deployment: Fully automated to production.
