# Resources in Software Development

## Human Resources
People involved in application development:
- Developers
- Test Engineers
- Support Engineers
- Database Administrators
- Project Managers, HR, System Admins, etc.

## IT Resources
Technical/software resources required:

### Software Types
- System Software (e.g., OS like Linux, Windows)
- Application Software (e.g., WhatsApp, Microsoft Word)

## Recap:
- Kubernetes manages containers with auto-scaling and balancing.
- Terraform automates infrastructure with code.
- Ansible manages configuration with playbooks.
- Linux is a popular open-source OS for servers.
- Shell scripts automate repetitive Linux tasks.
- AWS provides cloud servers and storage.
- GitHub hosts code and enables CI/CD integration.
