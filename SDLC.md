# Software Development Life Cycle (SDLC)

This is the process followed to build and deliver software.

## Phases in SDLC:
- Requirement Collection → Understand what the client/user needs.
- Analysis → Analyze requirements and plan how to solve them.
- Design → Prepare system design (UI, database, architecture).
- Coding → Developers write the code.
- Testing → QA team tests the code for bugs.
- Installation (Deployment) → Software is released to the users.
- Maintenance → Fix issues, update features after release.

In SDLC,  
**Dev (Development)** covers: Requirement → Analysis → Design → Coding → Testing.  
**Ops (Operations)** covers: Installation → Maintenance.

So, **DevOps = Development + Operations working together.**
